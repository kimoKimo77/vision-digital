# 🌐 رؤية الرقمية | VISION DIGITAL

موقع ويب تعريفي عصري ومستجيب (Responsive) لوكالة تقنية رقمية متخصصة في تطوير المواقع، تطبيقات الهواتف الذكية، وبناء الهويات البصرية. تم تصميم الواجهة بأسلوب مذهل يعتمد على المؤثرات الزجاجية (**Glassmorphism**) مع دعم كامل للوضع الداكن والفاتح.

---

## ✨ المميزات التقنية (Features)

*   **🎨 تصميم عصري (Glassmorphism):** واجهة مستخدم مستقبلية جذابة تعتمد على الخلفيات الشفافة والمضببة (Blur effects).
*   **🌓 الوضع الداكن والتلقائي (Dark Mode):** تحويل كامل وسلس بين الوضعين الداكن والفاتح مع حفظ تفضيل المستخدم في المتصفح (`localStorage`).
*   **📱 متوافق مع جميع الشاشات (Responsive Design):** تجربة تصفح مثالية على الهواتف، الأجهزة اللوحية، والشاشات المكتبية الكبيرة باستخدام نظام شبكة Tailwind المتطور.
*   **🔍 تصفية معرض الأعمال (Portfolio Filter):** نظام تفاعلي سريع يعتمد على Vanilla JavaScript لتصفية المشاريع بحسب التصنيف دون الحاجة لإعادة تحميل الصفحة.
*   **🚀 أداء فائق السرعة:** الكود يعتمد على أحدث تقنيات الـ CSS والـ JS المستضافة عبر شبكات توصيل المحتوى السريعة (CDNs).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

*   **HTML5** - الهيكل الأساسي للصفحة ودعم اللغات التي تُكتب من اليمين إلى اليسار (`dir="rtl"`).
*   **Tailwind CSS** - لإدارة التصاميم وتنسيق الألوان والتجاوبية بشكل سريع.
*   **Lucide Icons** - مكتبة أيقونات متجهة (SVG) خفيفة الوزن وعصرية تضفي لمسة جمالية على الواجهة.
*   **Vanilla JavaScript** - لإضافة الحركات التفاعلية، التحكم بالقائمة الجانبية للهواتف، وتغيير الأنماط الليلية.
