# 🌐 رؤية الرقمية | VISION DIGITAL

موقع تعريفي مستجيب لوكالة خدمات رقمية، مبني حاليًا باستخدام HTML وTailwind CSS وJavaScript عادي.

## المميزات

- تصميم متجاوب يدعم العربية واتجاه RTL.
- الوضع الداكن والفاتح وتصفية معرض الأعمال.
- صفحات مصادقة جاهزة للربط مع Supabase Auth: تسجيل الدخول، إنشاء حساب، استعادة كلمة المرور، عرض الحساب وتسجيل الخروج.
- إعداد نشر AWS يستخدم GitHub Actions OIDC بدل مفاتيح AWS طويلة الأجل.

## ملفات المشروع

```text
├── index.html
├── login.html
├── account.html
├── auth-client.js
├── auth-config.js
├── SECURITY.md
├── .github/workflows/aws.yml
└── README.md
```

## تفعيل المصادقة

1. أنشئ مشروعًا في Supabase.
2. افتح `auth-config.js` وضع رابط المشروع ومفتاحه **publishable/anon**. هذا المفتاح مخصص للمتصفح؛ لا تضع مطلقًا مفتاح `service_role` في ملفات الواجهة.
3. في إعدادات Supabase Auth، أضف عنوان الموقع الفعلي وعناوين إعادة التوجيه لـ `account.html`، وراجع سياسة تأكيد البريد وكلمات المرور.
4. افتح `login.html` عبر خادم محلي أو استضافة HTTPS؛ لا تفتح الملف مباشرة باستخدام `file://`.
5. اختبر التسجيل وتأكيد البريد والدخول واستعادة كلمة المرور والخروج.

**مهم:** صفحات HTML الثابتة لا تستطيع حماية محتوى خاص بمفردها. صفحة `account.html` توضح حالة الجلسة فقط؛ حماية البيانات تتطلب قواعد RLS وسياسات صلاحيات صحيحة في Supabase أو خادمًا خلفيًا موثوقًا.

## تهيئة النشر إلى AWS

سير العمل `.github/workflows/aws.yml` يتطلب متغيرات GitHub Actions التالية: `AWS_REGION`, `AWS_ROLE_ARN`, `ECR_REPOSITORY`, `ECS_SERVICE`, `ECS_CLUSTER`, `ECS_TASK_DEFINITION`, `CONTAINER_NAME`.

يجب إعداد موفر OIDC ودور IAM محدود الصلاحيات في AWS. يفشل سير العمل عمدًا إذا كانت المتغيرات غير مهيأة أو لم يوجد `Dockerfile` وملف تعريف مهمة ECS. المستودع الحالي موقع HTML ثابت ولا يحتوي على هذين الملفين؛ حدّد أولًا ما إذا كان ECS مطلوبًا أم أن الاستضافة الثابتة أنسب.

يوفر `supabase/schema.sql` مثالًا لجدول ملفات شخصية بسياسات RLS تقيد كل مستخدم ببياناته، وتُشغّل اختبارات التحقق الثابتة عبر `node --test tests/*.test.mjs`. هذه الاختبارات لا تستبدل اختبارات تكامل فعلية بمشروع Supabase مُهيأ.\n\nللتفاصيل الأمنية وخطوات الإعداد، راجع [SECURITY.md](./SECURITY.md).
